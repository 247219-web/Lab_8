# FitTrack — мобільний застосунок для фітнес-тренувань

## Про проєкт
**FitTrack** — це навчальний прототип мобільного застосунку, який допомагає користувачам планувати фізичну активність, записувати тренування та стежити за власним прогресом.

Застосунок вирішує проблему відсутності зручного місця для обліку тренувань. Користувач може бачити історію занять, тривалість активності та виконання щоденної цілі.

> **Примітка:** це демонстраційний HTML-прототип. Він не є справжнім мобільним застосунком, не синхронізується із сервером і зберігає зміни лише під час відкритої сторінки.

## Основні функції
- перегляд тренувань за категоріями;
- додавання нового тренування;
- облік тривалості занять;
- перегляд кількості тренувань і загального часу активності;
- відстеження щоденної цілі;
- перегляд історії тренувань.

## Для кого призначений продукт
- для початківців, які хочуть сформувати звичку тренуватися;
- для людей, які регулярно займаються спортом;
- для користувачів, які хочуть бачити власний прогрес.
