# FitPulse — Мобільний застосунок для фітнес-тренувань

**FitPulse** — це мобільний фітнес-застосунок, який допомагає користувачам планувати тренування, відстежувати виконання вправ і підтримувати регулярність занять удома або в залі.

## Яку проблему вирішує система
Багато людей кидають тренування через відсутність зрозумілого плану, плутанину у вправах та втрату мотивації. FitPulse об'єднує готові програми, таймер підходів і журнал прогресу в одному простому екрані.

## Основні функції
* **Каталог тренувань:** підбірки тренувань за цілями (кардіо, сила, розтяжка, ранкова руханка) та рівнем складності.
* **Картка вправи та таймер:** опис техніки виконання, кількість підходів і повторень, таймер відпочинку.
* **Трекер прогресу:** відмітка виконаних тренувань, підрахунок активних днів і витрачених калорій.
* **Нагадування:** сповіщення про заплановані тренування у зручний час.

## Для кого цей продукт
* Початківців, яким потрібні прості структуровані тренування без складних таблиць.
* Користувачів, які займаються вдома або в тренажерному залі й хочуть фіксувати підходи та час відпочинку.
* Людей, яким важливо бачити свій тижневий прогрес і не пропускати заняття.
