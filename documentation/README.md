# HelpDesk — система підтримки користувачів

## Про проєкт
**HelpDesk** — це вебсистема для реєстрації та відстеження звернень користувачів до служби технічної підтримки. Вона допомагає не губити запити, призначати відповідальних працівників і бачити поточний стан кожної проблеми.

> Це навчальний прототип. Дані зберігаються лише в пам’яті браузера під час відкритої сторінки; серверної частини та справжньої авторизації немає.

## Яку проблему вирішує
Коли користувачі повідомляють про проблеми через різні канали (усно, телефоном або в месенджерах), звернення легко загубити. HelpDesk збирає їх в одному місці та робить процес підтримки прозорішим.

## Основні можливості
- перегляд списку звернень;
- пошук за темою або номером заявки;
- фільтрація за статусом;
- створення нового звернення;
- перегляд пріоритету, категорії та дати створення;
- демонстраційна зміна статусу заявки.

## Для кого призначений продукт
- **Користувачі** — створюють звернення та описують проблему;
- **Працівники підтримки** — переглядають заявки й опрацьовують їх;
- **Адміністратори** — контролюють навантаження та якість підтримки.
