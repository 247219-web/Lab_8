# Довідник з інсталяції та запуску FitTrack

## 1. Необхідні інструменти
Для запуску прототипу потрібні:
- комп’ютер, ноутбук або смартфон;
- сучасний браузер (Google Chrome, Mozilla Firefox, Microsoft Edge або Safari);
- файли проєкту з GitHub.

Для редагування коду можна використовувати Visual Studio Code або будь-який текстовий редактор.

Сервер, база даних і додаткові бібліотеки не потрібні.

## 2. Завантаження проєкту
1. Відкрийте GitHub-репозиторій FitTrack.
2. Натисніть **Code → Download ZIP**.
3. Розпакуйте архів у зручну папку.

Або склонуйте репозиторій командою:
```bash
git clone https://github.com/USERNAME/documentation-lab-fittrack.git
```

## 3. Запуск
1. Відкрийте папку `documentation-lab-fittrack`.
2. Знайдіть файл `index.html`.
3. Відкрийте його подвійним натисканням.
4. Сторінка FitTrack запуститься у браузері.

## 4. Перевірка роботи
Переконайтеся, що:
- відображається назва FitTrack;
- на головному екрані є статистичні картки;
- відображається щоденна ціль;
- кнопка «Додати тренування» відкриває форму;
- після збереження тренування воно з’являється в історії;
- загальна кількість тренувань і хвилин оновлюється.

## 5. Типові проблеми
| Проблема | Рішення |
|---|---|
| Файл не відкривається | Перевірте, чи має він розширення `.html` |
| Кнопки не працюють | Перевірте, чи увімкнений JavaScript у браузері |
| Дані зникли після оновлення | Це очікувана поведінка демонстраційного прототипу |
| Інтерфейс некоректно відображається | Спробуйте оновити браузер або відкрити сторінку на ширшому екрані |
