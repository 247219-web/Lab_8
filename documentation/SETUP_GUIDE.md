# Довідник з інсталяції та запуску

## 1. Вимоги
Для запуску навчального прототипу потрібні:
- комп’ютер або ноутбук;
- сучасний браузер (Chrome, Firefox, Edge або Safari);
- файли проєкту з GitHub або ZIP-архіву.

Сервер, база даних, Node.js та додаткові бібліотеки не потрібні.

## 2. Отримання проєкту
**Варіант А — через GitHub**
1. Відкрийте сторінку репозиторію.
2. Натисніть **Code → Download ZIP** або скопіюйте репозиторій командою:
   ```bash
   git clone https://github.com/USERNAME/documentation-lab-helpdesk.git
   ```
3. Розпакуйте архів, якщо завантажували ZIP.

**Варіант Б — локально**
1. Створіть папку `documentation-lab-helpdesk`.
2. Збережіть у ній `index.html` та Markdown-файли.

## 3. Запуск
1. Відкрийте папку проєкту.
2. Знайдіть файл `index.html`.
3. Двічі клацніть файл або відкрийте його через браузер.
4. Дочекайтеся завантаження сторінки HelpDesk.

## 4. Перевірка роботи
Переконайтеся, що:
- відображається заголовок **HelpDesk**;
- видно картки зі статистикою та список демонстраційних заявок;
- пошук змінює список відповідно до введеного тексту;
- фільтр показує заявки вибраного статусу;
- кнопка **Створити звернення** відкриває форму;
- після заповнення форми нова заявка з’являється у списку.

Якщо сторінка не відкривається, перевірте, чи файл має розширення `.html`, і спробуйте інший браузер.

## 5. Типові проблеми
| Проблема | Можливе рішення |
|---|---|
| Браузер показує HTML-код як текст | Перевірте розширення файлу — має бути `.html` |
| Кнопки не реагують | Увімкніть JavaScript у браузері |
| Заявки зникли після перезавантаження | Це очікувана поведінка демонстраційної версії |
