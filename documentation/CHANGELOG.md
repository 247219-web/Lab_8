# Журнал змін FitTrack

У цьому файлі записані основні етапи розробки навчального проєкту.

## [1.0.0] - 2026-11-23
- Створено першу версію HTML-прототипу FitTrack.
- Додано головну панель зі статистикою активності.
- Реалізовано форму додавання тренування.
- Додано історію занять і підрахунок загальної тривалості.

## [0.3.0] - 2026-11-20
- Підготовлено приклади API для тренувань і статистики.
- Додано приклади JSON-запитів та відповідей.
- Описано основні коди помилок.

## [0.2.0] - 2026-11-18
- Створено інструкцію користувача.
- Додано розділ FAQ.
- Підготовлено довідник зі встановлення та запуску.

## [0.1.0] - 2026-11-15
- Створено структуру репозиторію.
- Сформовано ідею та основні функції FitTrack.
- Додано початковий опис проєкту.
